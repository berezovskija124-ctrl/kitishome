# Расписание КИТиС — экран в колледже

Сайт для большого экрана в колледже. В нём только пять разделов:

- **Группы** — список групп; нажали на группу — открылось её расписание на неделю: что идёт сейчас, сколько осталось до конца пары, следующая и прошлая неделя;
- **Звонки** — расписание звонков на понедельник и на вторник – субботу, сколько осталось до звонка;
- **Преподаватели** — неделя преподавателя;
- **Кабинеты** — какой кабинет сейчас занят и неделя кабинета;
- **Итоги** — выполнение нагрузки по группе, преподавателю или кабинету, ячейка в ячейку как на странице «Итоги» сервера расписания.

Дизайн тот же, что у основного сайта расписания: те же карточки, у каждого предмета свой цвет. Вход, меню, избранное и ссылки на другие сайты убраны. В шапке крупно показаны часы, дата и что сейчас: пара или перемена и сколько до звонка.

Данные берутся с сервера расписания колледжа http://94.72.18.202:8083.

## Как экран обновляется

1. **Данные.** Робот на GitHub (`.github/workflows/update-schedule.yml`) скачивает расписание с сервера колледжа:
   - с понедельника по субботу — каждый час с 06:23 до 20:23 по Калининграду;
   - в воскресенье — каждые 2 часа с 10:23 до 20:23, чтобы не пропустить публикацию следующей недели.

   Если расписание изменилось, робот сохраняет `data/kitis-data.js`, и GitHub Pages сам публикует сайт заново.
2. **Страница на экране.** Раз в час страница сама перезагружается и берёт свежие данные. Это происходит только тогда, когда экран никто не трогает хотя бы 2 минуты и сайт доступен. Если интернета нет, на экране остаётся последнее загруженное расписание, а не ошибка браузера. Часы, «сейчас идёт» и таймеры работают и без интернета.
3. **Бездействие.** Если экран не трогали 3 минуты, он сам возвращается к списку групп. Курсор мыши прячется через 5 секунд без движения.
4. **Масштаб.** Всё увеличивается под ширину экрана: на 1920×1080 и на 4K выглядит так же, как на макете, только крупнее. На экране поуже (1366 px или вертикальном) шапка становится компактнее.
5. **Экран не гаснет**, пока открыт сайт, если браузер это умеет (Chrome, Edge). Надёжнее всего ещё и отключить сон экрана в настройках компьютера.

## Как выложить на GitHub

1. Создайте на GitHub новый репозиторий, например `kitis-ekran`, и загрузите в него всё содержимое этой папки, включая скрытые `.github` и `.nojekyll`.
2. Включите сайт: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**. Через минуту сайт откроется по адресу `https://ИМЯ.github.io/kitis-ekran/`.
3. Разрешите роботу сохранять данные: **Settings → Actions → General → Workflow permissions → Read and write permissions** → **Save**.
4. Запустите робота первый раз вручную: **Actions → «Обновление расписания» → Run workflow**. Дальше он будет работать по расписанию сам.

GitHub отключает робота, если в репозитории 60 дней не было никаких изменений. Пока расписание обновляется, изменения есть каждый день. После долгих каникул может понадобиться снова нажать **Enable workflow** на вкладке Actions.

## Как открыть на экране в колледже

Удобнее всего — браузер в режиме киоска: на весь экран, без адресной строки и вкладок.

**Windows (Chrome или Edge).** Создайте ярлык с такой командой:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk https://ИМЯ.github.io/kitis-ekran/ --noerrdialogs --disable-session-crashed-bubble --disable-infobars
```

Для Edge — `msedge.exe` с теми же параметрами. Чтобы сайт открывался сам после включения компьютера, положите ярлык в папку автозагрузки: Win+R → `shell:startup`.

**Linux:**

```
chromium --kiosk https://ИМЯ.github.io/kitis-ekran/ --noerrdialogs --disable-session-crashed-bubble
```

Выйти из режима киоска — Alt+F4.

Не забудьте отключить сон и выключение экрана в настройках электропитания.

Для проверки можно открыть сайт с демо-временем: `?now=2026-11-12T10:30` в адресе. Тогда в шапке появляется надпись «демо-время». На самом экране адрес должен быть без `?now=`.

## Что в папке

| Файл | Что это |
|---|---|
| `index.html` | страница экрана |
| `js/page-index.js` | код страницы |
| `js/kiosk.js` | поведение экрана: масштаб, возврат к группам, перезагрузка раз в час, курсор |
| `dc-runtime.js` | движок, который отрисовывает страницу |
| `kitis-model.js` | расписание, звонки, недели, «сейчас идёт», цвета предметов |
| `data/kitis-data.js` | данные с сервера колледжа (обновляет робот) |
| `parser/kitis-parser.js`, `parser/update.mjs` | робот: читает страницы сервера расписания |
| `.github/workflows/update-schedule.yml` | расписание запуска робота |
| `tests/results-match.js` | проверка: «Итоги» на экране совпадают с сервером |
| `robots.txt` | экран не попадает в поисковики |

## Проверка

```
python3 -m http.server 8765
node tests/results-match.js
```

Тест открывает «Итоги» всех групп и всех преподавателей и сравнивает каждую ячейку с данными сервера. Нужен Playwright: `npm i playwright`, затем `npx playwright install chromium`.
